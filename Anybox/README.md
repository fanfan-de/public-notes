# Anybox 项目笔记

这里是 Anybox 项目的长期知识入口，集中记录产品定位、整体架构、设计决策、模块实现、开发部署、问题分析与验证结论。范围覆盖 Anybox 宿主、Anybox Harness 及其他应用，已有内容从下面的索引进入。

## 项目与命名

| 名称 | 含义 |
| --- | --- |
| Anybox | 承载应用的宿主，负责应用管理、承载和退出协调等通用职责 |
| Anybox Harness | 拥有 Agent 执行、会话、模型和工具等业务的应用 |
| harness server | Anybox Harness 可部署在本机或远端的服务端核心 |
| Anybox Harness 客户端 | 提供界面、连接管理和业务请求转发的客户端 |
| Computer worker | 在实际设备上执行 Computer 工具、管理进程资源并保存执行事实的独立服务 |

名称与职责按各篇笔记标注的核对日期理解；项目的新实现和实际验证可以推动笔记修订。

- [Anybox 的逻辑架构、代码组织与运行时架构](Anybox%20的逻辑架构、代码组织与运行时架构.md)：从职责、十二个源码包和实际运行拓扑理解整个 Anybox，区分默认组合发行与最小安装宿主，并给出三种视图的对应表。
- [Anybox Harness 运行时架构](Anybox%20Harness%20运行时架构.md)：进程与 Nya 组件边界，Session、Run、RunRuntime、协议 Loop、Models 和工具环境的协作，以及完成、取消与恢复。

## 如何持续记录

新笔记直接放在 `Anybox/`，按一个可以独立理解的问题命名，并在本页增加链接。产品、宿主、应用、模型、工具、部署等细分主题通过本页分组、标签和关联链接组织；实际内容增加后再扩展索引。

记录时保留以下信息：问题与背景、当前结论、选择该方向的理由、相关方案与取舍、适用范围、证据来源和未验证事项。实现状态随时间变化的内容标明核对日期，运行结果注明实际验证条件；设计建议与已完成能力分开描述。

本目录保存项目知识与决策脉络。接口和操作细节可链接项目文档，架构笔记保留足够的解释与核对入口；后续围绕同一主题补充已有笔记，独立主题另建笔记并互相链接。

通用 Agent 知识参见 [Agent 专题](../Agent/README.md)，跨项目可复用的实验参见 [实践记录](../实践/README.md)，项目特有的结论回到本模块索引。
